Precision Audio Control

Everything You Need to Manage Tab Sound

From independent volume sliders to native Chrome Tab Group integration, Hush delivers studio-grade acoustics inside your browser.

🎚️

Individual Tab Volume Control

Adjust any browser tab's volume independently from 0% to 100%. Use precision mouse scrubbing, keyboard shortcuts, or mouse-wheel scrolling without affecting system-wide sound.

🔊

Dual Audio Interception

Controls HTML5 <audio> and <video> tags and intercepts Web Audio API AudioContext pipelines with an exponential GainNode multiplier to prevent clipping or popping.

📂

Automatic Activity Categorization

Tabs are classified into 8 activity domains: Entertainment, Music, Work, Study, Gaming, Communication, Social, and Other. Master sliders let you mute entire groups at once.

🎯

One-Click Focus Modes

Apply pre-configured acoustic presets (Study, Gaming, Meeting) in a single click. Hover over any mode to preview which tabs will be prioritized or muted before applying.

📑

Native Chrome Tab Groups

Synchronize your browser with Chrome's native chrome.tabGroups API. Turn 50 unorganized tabs into clean, color-coded native tab groups with one click.

🚀

Powered by react-fastload

Built with react-fastload for tiered scheduling and resource deduplication, guaranteeing zero UI freeze even with 100+ open tabs.

Audio Architecture

How Hush Controls Browser Sound

A multi-tier Manifest V3 pipeline that intercepts both standard media tags and advanced Web Audio API audio graphs without latency.

Step 1

React 19 Popup

Renders precision sliders and HUD scheduled through react-fastload with cached favicons.

Step 2

Service Worker

Coordinates per-tab state, cleans up closed tabs, and persists volume levels via chrome.storage.local.

Step 3

Isolated Content Script

Hooks HTML5 media elements (play, loadstart) and handles direct volume synchronization.

Step 4

Main-World Gain Hook

Inserts master GainNode before destination with smoothed setTargetAtTime transitions.

Get Started

How to Install Hush

Hush is officially published on the Chrome Web Store. You can install it directly with one click, or load it as an open-source unpacked extension.

Add to Chrome — Official Web Store
  1. Clone the GitHub repository:
    git clone https://github.com/abhishek-kumar-pundir/Hush.git
  2. Install dependencies and build the extension:
    npm install && npm run build
  3. Open Chromium (Chrome, Brave, Edge) and navigate to chrome://extensions.
  4. Enable Developer mode in the top-right corner.
  5. Click Load unpacked and select the dist directory generated by the build.
  6. Pin Hush to your browser toolbar for quick volume access!
